# Nostos for Unraid

Unraid Community Applications template for [Nostos](https://github.com/Christian-Gennari/Nostos), a self-hosted commonplace book: read EPUB, PDF and audiobooks, keep passages with their source, and write from them.

The template's source of truth is [`deploy/app-stores/unraid/`](https://github.com/Christian-Gennari/Nostos/tree/main/deploy/app-stores/unraid) in the Nostos repository; this repository is a copy so Community Applications can scan it. Support: [Nostos issues](https://github.com/Christian-Gennari/Nostos/issues).
